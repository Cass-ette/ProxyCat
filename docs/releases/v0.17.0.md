## 新功能

- **离线安装与升级**：DMG 内新增原生“安装 ProxyCat”入口，检测现有版本，确认后等待旧版安全退出、替换并打开新版。复制或校验失败时保留、恢复旧版；也支持直接分发内部测试包。
- **诊断与复检**：分别检查本地文件、内核运行、代理端口和真实 HTTPS 请求，按实际故障提供恢复或检测入口。操作后重新验证，网络状态变化时撤下旧结果。
- **订阅后台更新**：连接可用时定期更新订阅，显示最近成功时间和失败原因。更新前校验配置，失败保留旧配置，成功保存与当前内核是否已应用分别显示。
- **网站偏好**：在网站检测结果和连接记录中设置“总是走代理”或“总是直连”，也可恢复订阅默认。偏好独立保存，订阅更新后继续保留；规则模式下通过实际请求、命中规则与节点链验证生效。

## 改进

- 诊断报告不再随状态轮询闪退；网络变化后保留为带时间的上次记录，停用过期修复操作，支持主动清除。复检失败仍保留历史供回看。
- 普通内核应用配置时保留当前模式及仍有效的手选节点；应用失败时恢复旧配置并验证，无法确认恢复时明确提示。
- 订阅服务器返回 HTTP 错误时保留具体状态与对应建议，更新失败在界面显示原因，并继续保留旧配置及上次成功时间。
- DMG 保留常见拖动安装为主入口，自动安装器作为可选项；安装窗口统一使用原生样式，并显示进度、保留简短错误说明与可展开详情。
- TUN 会话中的新配置先保存并显示待生效，正常关闭或重新开启 TUN 时应用，后台更新不主动切换接管方式。
- GeoIP 自动更新继续使用 Mihomo 内置能力；GeoIP 更新时间及失败原因的界面展示暂缓。

## 安装说明

新安装请下载 DMG，打开后将 ProxyCat 拖到“应用程序”；更新旧版也可使用下方的“安装 ProxyCat”，由安装器等待旧版安全退出后替换并打开。已安装用户可通过应用内“检查更新”升级，订阅和设置会保留。附带的 installer ZIP 用于兼容旧版更新器。

当前应用尚未进行 Apple Developer ID 签名和公证；首次打开如被 macOS 拦截，请到“系统设置 → 隐私与安全性”中允许打开。

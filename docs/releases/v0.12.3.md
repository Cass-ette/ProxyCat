## 修复

- 修复从规则模式切换到全局模式时，`GLOBAL` 默认选中 `DIRECT`、流量意外直连导致连接失败的问题。全局组尚未选择代理时，优先使用规则的默认节点组；已选的全局节点保持不变。
- 修复当前节点和开启代理后的测速未跟随模式的问题：全局使用 `GLOBAL`，直连使用 `DIRECT`，规则使用规则节点组。
- 切换模式后清除旧模式的测试结果；全局节点准备失败时保留原模式并显示原因。
- 修复连接测试失败时应用只显示 `Command failed: proxyctl test --json exited with status 1` 的问题。
- JSON 连接测试现在会返回 Google/GitHub 各自的结果和具体网络错误，包括异常 HTTP 状态码，应用可以显示失败位置。

## 安装与更新

已安装的用户可在 ProxyCat 中选择“检查更新” → “安装更新”，安装完成后按提示重启应用。新用户下载 DMG，打开后将 ProxyCat 拖入 Applications。

当前应用尚未进行 Apple Developer ID 签名和公证，首次打开如被系统拦截，请到“系统设置 → 隐私与安全性”中允许打开。

## 新功能

- **菜单栏代理状态颜色**：绿色实心猫表示系统代理已开启，灰色轮廓猫表示系统代理关闭。打开或关闭菜单不再改变代理状态图标。
- **直连与异常状态**：直连模式显示蓝色；系统代理开启但代理引擎停止时显示橙色警告，避免误以为代理正常工作。悬停可查看状态说明。

## 改进

- 图标跟随真实的系统代理、代理引擎和模式状态变化；外部改变状态时，会在下一次状态刷新后更新。颜色表示开关与模式，不代表已通过网络连通性测试。
- **统一版本号规则**：采用“主版本.功能版本.修复版本”，新增功能升功能版本，仅修复升修复版本；版本集中维护，构建和发布时检查标签、应用和更新日志是否一致。

## 安装与更新

已安装用户可通过“检查更新”查看内容后安装，并按提示重启。新用户下载 DMG，打开后将 ProxyCat 拖入“应用程序”。

当前应用尚未进行 Apple Developer ID 签名和公证，首次打开如被系统拦截，请到“系统设置 → 隐私与安全性”中允许打开。

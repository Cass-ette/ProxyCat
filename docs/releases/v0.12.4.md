## 修复

- **更新检查**：改用 GitHub 发布文件中的更新信息，避免共享网络出口耗尽匿名 API 额度后无法检查更新；主通道不可用时自动尝试备用通道。
- **离线更新日志**：检查失败时仍显示随应用附带的当前版本日志，同时保留失败原因和重试入口，不再出现空白说明页面。
- 更新服务限流、拒绝访问及异常状态码现在显示具体原因，便于判断是否需要稍后重试。

## 安装与更新

旧版若检查更新失败，请下载本页 DMG，退出 ProxyCat 后将新版拖入“应用程序”替换。安装本版后可使用新的更新通道。

当前应用尚未进行 Apple Developer ID 签名和公证，首次打开如被系统拦截，请到“系统设置 → 隐私与安全性”中允许打开。

## 新功能

- **TUN 接管**：新增独立 TUN 开关，经 macOS 管理员授权后接管应用流量；规则、全局、直连继续决定分流方式。只有内核确认隧道已建立后才显示开启。
- **TUN 清理与恢复**：关闭 TUN 后恢复普通代理内核；退出应用、应用进程意外结束或校园网自动断开时停止隧道。授权取消或开启失败时恢复原连接；不会自动重连 TUN。
- **问题反馈**：菜单新增“问题反馈（Issue）”，可前往 GitHub 填写问题报告或功能建议。
- **模式说明**：规则、全局、直连按钮旁新增 ❓，点击即可展开简短区别，再次点击收起。

## 安装与更新

已安装用户可通过“检查更新”安装；新用户下载 DMG，将 ProxyCat 拖入“应用程序”。检查和下载更新需要访问 GitHub。

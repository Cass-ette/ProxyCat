## 修复

- **更新前的网络提醒**：检查更新和安装更新时固定显示提示：更新文件来自 GitHub，部分网络可能需要先开启代理或 VPN；连接失败时请开启后重试。提示不随更新日志滚动消失，也不会强制开启代理。
- **下载失败提示**：连接超时、域名解析失败及下载中断时，显示可执行的网络建议，原始报错移入可展开的“技术详情”，避免长串 URL 和 IP 占满错误区域。
- 下载失败后保留已查看的目标版本，开启代理后可点击“重试安装”；重试成功会清除上次的报错详情。

## 安装与更新

检查和下载更新需要访问 GitHub。部分网络可能需要先开启代理或 VPN，再使用“检查更新”或“重试安装”。

新用户下载 DMG，打开后将 ProxyCat 拖入“应用程序”。当前应用尚未进行 Apple Developer ID 签名和公证，首次打开如被系统拦截，请到“系统设置 → 隐私与安全性”中允许打开。
